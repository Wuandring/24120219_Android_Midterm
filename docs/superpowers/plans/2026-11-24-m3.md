# M3 — Dark Concert Canvas Renderer Implementation Plan

**Goal:** Render the specified venue in one CustomPainter with cached resources, culling and LOD.
**Spec:** agents_md_flutter_concert_seat_map.md sections 3, 4 and milestone M3.
**Architecture:** SeatMapPaintCache owns immutable geometry/text and reusable paints/shader. SeatMapPainter reads ValueListenables for camera and rendering state through Listenable.merge. Screen owns and disposes caches/notifiers; LayoutBuilder fits the full world. Rendering state is a snapshot, not the M5 selection controller.
**Tech Stack:** Flutter SDK only.

## Design
Navy #0B1120 venue and slate #1E293B stage; cyan Standing, gold VIP, indigo Standard, emerald selected. T-stage and cyan gradient spotlight are the visual focus. System sans typography: stage 28 world units, zone 22, seat code 7.5. Keep aisles empty; label each block above its seats. Single canvas fills available safe area in both orientations.
