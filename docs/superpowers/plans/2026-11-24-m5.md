# M5 — Ticket Sheet and Spotlight Implementation Plan

**Goal:** Persistent expandable selection sheet, immediate two-way sync, animated seat focus and rotation-safe layout.
**Spec:** agents_md_flutter_concert_seat_map.md M5 and explicit user requirements.
**Architecture:** Map controller owns selection, inspection, focus and immutable render snapshot. Sheet reads controller and emits remove/focus actions. Screen owns sheet/camera/pulse animations; updates full canvas camera viewport only on actual canvas size changes; explicit focus uses sheet bottomInset. Optional screen-space edge clearance in engine allows boundary seats to center without changing fit scale; defaults preserve existing engine behavior.
**Tech Stack:** Flutter SDK only.
