# M2 — Math Engine Implementation Plan

**Goal:** Pure Dart camera math and geometry hit-testing, with no UI changes.
**Architecture:** Immutable CameraTransform; static CoordinateTransformer for conversion/visible bounds; ViewportClamper owns fit, limits and resize; HitTester converts screen to world before testing source geometry.
**Tech Stack:** Dart SDK and flutter_test only.
**Spec:** agents_md_flutter_concert_seat_map.md sections 5 and 7 (M2).

## Constraints and decisions
- World 1600×1200; scale range 0.9–4.5 times fitScale.
- Clamp large maps to viewport edges and center smaller maps on each axis.
- Resize preserves zoom relative to fitScale and the old viewport's center world point, subject to clamping.
- Circle edges and rectangle edges are inclusive; tolerate only floating-point roundoff at edges.
- Hit-testing returns booked/locked seats too; selection rules belong to future state layer.
- Reject nonfinite coordinates, nonpositive scale/viewport/world dimensions.
